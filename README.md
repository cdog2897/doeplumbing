# Doe Plumbing website

A static, phone-first website for Doe Plumbing in Laramie, Wyoming. Built with Vite, React, and TypeScript. No backend or form service is required.

## Run locally

From this directory:

    npm install
    npm run dev

For a production check:

    npm run lint
    npm run build
    npm run preview

## Business information

The site uses the phone number **(307) 745-0571** and **3708 E Grand Ave, Laramie, WY 82070**. Service categories and residential/commercial wording are based on public listings and customer reviews. Business hours are deliberately not stated as exact hours because current public listings disagree; the page asks visitors to call to confirm.
